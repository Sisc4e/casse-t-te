La Main et l'Œil

Le coffre de l'horloger Vautrin se verrouille par quatre mécanismes. L'un de vous est enfermé avec eux, sans aucun plan. L'autre possède tous les plans, mais ne voit pas le coffre. Vous n'avez que votre voix pour vous en sortir.

Les deux joueurs saisissent le même code, chacun sur son propre appareil. Le code génère la même énigme des deux côtés.

Votre rôle

Avant de commencer

  1. Un joueur tire un code et le dicte à l'autre.
  2. Chacun choisit un rôle différent et vérifie que le sceau affiché en haut de l'écran est identique des deux côtés.
  3. La Main lance le chrono. Ne montrez jamais votre écran : décrivez, questionnez, comptez les cases.

Pour essayer seul, ouvrez la page dans deux fenêtres avec le même code.
